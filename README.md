# CS129-PL

CMSC 129 group repository. Each folder is a separate program.

| Folder | What it is | Status |
|--------|------------|--------|
| `PE02/` | Lexical analyzer for IOL | Submitted (tag `pe02`) |
| `PE03/` | Non-recursive predictive parser | Submitted (tag `pe03`) |
| `IOL/`  | Course project: the IOL compiler and IDE | In progress |

## Running

Run `python main.py` from inside the folder you want, for example:

```
cd IOL
python main.py
```
